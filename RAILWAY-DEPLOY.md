# Railway Deploy - Cola Next

## Step 1: Railway Account
1. https://railway.app pe jao
2. GitHub se login karo

## Step 2: New Project
1. **"New Project"** pe click karo
2. **"Deploy from GitHub Repo"** select karo
3. `transparentvisionyt-cpu/cola-next-system` choose karo

## Step 3: Environment Variables
Railway dashboard → Variables tab mein ye add karo:

```
PORT=3000
ADMIN_USER=admin
ADMIN_PASS=AlphexAi
PHONE=03241281605
WHATSAPP=923241281605
```

## Step 4: Deploy
- Auto deploy start ho jayega
- 2-3 minute mein complete hoga
- Railway ek URL dega: `https://cola-next-xxxx.up.railway.app`

## Step 5: Update APK URLs
APK mein URL change karo:
- User App: `https://cola-next-xxxx.up.railway.app/user`
- Admin App: `https://cola-next-xxxx.up.railway.app/`

## Login Credentials
- Admin: `admin` / `AlphexAi`
- Customer: `distributor` / `AlphexAi`
